# RUKSA RELIC — Originality & Market Thesis

Status: qualitative position only. Do not assert "world first".

## Adjacent offerings exist
- Traditional legacy modernization consultants reverse-engineer business rules and build replacement services.
- Website-cloning tools reconstruct structure/style and can replay browser traces.
- Browser-use agents automate existing legacy interfaces.
- Accessibility repair agents improve interface semantics.

## Our designed differentiator
**Don't clone pages; resurrect task behavior.** One button launches observable exploration, produces an epistemically labeled behavior graph, generates an accessibility-forward replacement, runs actual original-vs-replacement transactions in disposable sandboxes, and packages executable tests plus coverage gaps for human migration review.

What is unusually demonstrable:
- Not visual similarity: transaction outcomes and failure states match fixture oracle.
- Not guesswork: unknown hidden business logic is not disguised as "recovered".
- Not a generic builder: the user starts from a live broken workflow, not a text product prompt.
- Not an open-ended agent tool platform: domain is specifically digital preservation and service continuity.

## Measured metrics to report
Parity journeys passed / tested; explicit UNKNOWN states; generated code build success; time to first valid modernization candidate; keyboard/Axe measured failures (with disclaimer); containment tests passed; actual Vultr model cost and latencies.

## Limitations and go-to-market
Begin with owned mock community portal and authorized pilots. Source-free reconstruction cannot infer all server rules. A human owner must approve behavior contract and migration. Commercial model after event: priced discovery/proof package and assisted migration, not auto-replacement of critical services.

## Refined originality argument

Avoid selling RELIC as "an AI that clones websites" (already common). The differentiated product is **counterfactual behavioral archaeology**: interrogating an authorized old workflow to discover rules, reconstructing a modern accessible implementation and testing whether users can accomplish equivalent tasks. Each discovered fact carries evidence and unknowns. A valid business case is low-risk scoped *continuity assessment* before a costly full migration, subject to future customer validation.

Technology, presentation, business value and originality are the official judging dimensions; use one end-to-end demo to demonstrate all four. See [Continuity Engineering](42-RELIC-2-0-NORTH-STAR.md).
