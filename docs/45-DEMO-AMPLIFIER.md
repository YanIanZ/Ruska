# The Resurrection Demo — Stage, Narrative and Showmanship

**Objective:** Make technology, originality and business value instantly understandable without fake execution.

## Stage story (target 3m 30s, edit to official video requirements)
00:00-00:20 — A fictional school/community service website from 2008. Users can still submit requests, but key behavior has no documented source.
00:20-00:50 — Browser archaeologist navigates real site in an isolated Vultr worker. Show clicks, form values and trace receipts rather than a fabricated terminal animation.
00:50-01:15 — Behavior Genome emerges. One conditional urgent-description rule is UNCERTAIN; AI proposes boundary probes.
01:15-01:45 — Generated accessible replacement builds in a disposable sandbox. Before/after interface feels dramatic but preserves the service journey.
01:45-02:25 — **Twist:** Candidate looks correct but violates urgent description rule. Parity Arena finds a reproducible counterexample. Human sees the exact 10-versus-30-character discrepancy.
02:25-02:55 — AI proposes a constrained patch; real build/test reruns. Show PASS only for actual exercised cases and an explicit UNKNOWN panel for untouched behavior.
02:55-03:20 — Execute harmless runaway script or blocked egress in disposable worker. Show actual timeout, teardown and healthy VM A.
03:20-03:30 — Export Continuity Passport with source, tests, unknowns and owner review notes.

## Product demonstration screens
- Museum Lobby: owned fixture, permission note and restore action.
- Fossil Microscope: live trace and observation timeline.
- Genome Atlas: flow graph, rule evidence and unknown ledger.
- Parity Arena: synchronized old-vs-new execution and a prominent red counterexample.
- Revival Passport: files/test report/security receipt/coverage limitations and owner signoff.
- Containment Window: real worker runtime, enforced cap and kill event.

## Judging narrative
Application of Technology = Vultr VM + Serverless Inference + actual browser and code execution. Presentation = dramatic before/after plus detected regression. Business Value = maintainers regain workflow knowledge and tested migration starting point. Originality = guided counterfactual behavioral archaeology with executable continuity evidence. These four criteria come from official event.

## Do not overclaim
No real institutional site restored; no source code recovered from black-box observation; no all-state parity; no accessible-to-everyone certification; no proof of microVM safety without real controls. Prototype's offline oracle is not browser AI.

## Demo preparation
Record clear sequence with independently corroborated capture, real counters and sanitized logs, actual run SHA and replayable test cases. Keep backup sanitized video of a *real earlier successful execution*, labeled as recorded, if live connectivity fails. Never pretend playback is live.
