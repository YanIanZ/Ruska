# RUKSA RELIC — Restoration Studio UX

**Status:** Proposed product screens, not implemented.

1. **Museum Lobby:** choose project-owned legacy website; show why permission is required.
2. **Fossil Viewer:** live sandbox browser on left, observed actions and captured state on right; visible run status and limits.
3. **Behavior Genome:** node graph of states, fields, validation, transitions. OBSERVED, INFERRED, UNKNOWN with textual status and evidence.
4. **Rebirth Studio:** original 2008 portal next to generated new accessible UI, actual build status, source revision and safe preview.
5. **Parity Arena:** matched input cards and output diffs. Any important mismatch shows FAIL; highlight unresolved unknowns.
6. **Revival Capsule:** export generated code, behavior contract, reproducible tests, screenshot/trace refs, limitations and owner sign-off.
7. **Containment Window:** actual worker telemetry and denied network/timeout outcomes.

Accessibility: native semantic controls, labeled inputs, keyboard-only path, focus and error summaries, aria-live run status, color-independent PASS/FAIL marks. Automated axe checks alone are not WCAG compliance certification.

Design language: editorial museum-like framing, aged paper palette for old app, crisp accessible modern replacement, precise before/after split. Avoid third-party trademarks and fabricated metrics.
