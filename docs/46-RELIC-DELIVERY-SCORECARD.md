# RELIC 2.0 — Priority Scorecard and Six-Day Cutline

Status: proposed implementation plan, owner-controlled, not active deployment.

## Critical path
1. Vultr VM A backend + inference model responding through official endpoint.
2. An owned legacy portal hosted for safe exploration.
3. Sandboxed Playwright executes browser discovery with signed/scoped job capabilities and network isolation.
4. Inference proposes an explicit rules/Genome candidate with known uncertainty.
5. A new UI candidate is actually generated, built, served in an isolated worker.
6. Paired browser tests find the intentional urgent-description mismatch and a corrected candidate passes.
7. Live public site shows trace/unknown ledger and exports test/code bundle.
8. Real containment demonstration recorded; publish full submission.

## P0 / Must ship
- Actual sandbox execution on Vultr, strict egress with no secrets, resource and cleanup lifecycle.
- Old/new paired functional evaluation of 4 fixed synthetic cases.
- Real AI model usage for planning or codegen, with actual model name logged.
- At least one counterfactual probing decision and evidence of observed rule (not hardcoded as agent guess).
- Human review, explicit UNKNOWNs and a reproducible test artifact.
- Working public URL and final submission.

## P1 / Standout if P0 done
- Minimized counterexample, automated probe prioritization, keyboard/a11y checks, screenshot-backed comparisons.
- Continuity Passport integrity binding, replay CLI, multiple candidate revisions.
- Sophisticated side-by-side web interface.

## P2 / Post-hackathon
- Enterprise policy registry, multiple authorized web applications, multi-tenant service, real API/connectors and production cutover.
- Rich multiagent collaboration, microVM worker fleet, longitudinal software aging analysis.

## Exit checkpoints (Asia/Jakarta)
Nov 3: cloud VM/inference access, owned fixture available, web shell up.
Nov 4: real browser from worker VM, bounded and reproducible trace.
Nov 5: generated candidate builds; real fixed-case parity detects injected bug.
Nov 6: counterfactual probe and safety negative tests working.
Nov 7: polished UI, fresh-session E2E, artifact export, manual owner test.
Nov 8: submission freeze and verified presentation materials.

## Safety-gated cuts
If browser execution is not complete, stop fancy dashboard and work on sandbox. If candidate build is unstable, constrain output to typed UI component DSL compiled in isolated worker. If network policy fails, disable arbitrary run endpoints and do not substitute fake "contained" logs. If full auto-probing is not ready, show a bounded reviewed probe chosen by AI; do not label handwritten reference-model comparison as a browser observation. If real inference unavailable, disclose blocker; avoid other LLM provider for Challenge 1.

## Metrics and thresholds (targets, NOT achieved)
- 4/4 seeded fixture cases correct after repair; wrong candidate must fail at least one case.
- Counterfactual experiment reveals discrepancy around the 30-character urgent input boundary.
- 0 unapproved network destinations reached in defined negative tests (measure and show actual trace).
- 100% of marked OBSERVED rules accompanied by authorized browser trace refs.
- No critical security test failures at public demo release.
- Latency/compute/token cost measured from actual runs, not guessed.

## Commercial direction
Sell scoped **digital continuity assessment** (discovery + executable tests + gap map) before attempting full migration. This lowers risk of using a speculative auto-clone for critical public services. Institutional contracts, compliance, pricing and return-on-investment remain hypotheses until customer validation.
