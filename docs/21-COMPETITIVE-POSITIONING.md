# Competitive Positioning and Originality Strategy

## Landscape observed at planning time

Public lablab team ideas for this event include: [Airlock](https://lablab.ai/ai-hackathons/vultr-hackathon/airlock) (sandbox control plane), [PatchProof](https://lablab.ai/ai-hackathons/vultr-hackathon/patchproof) (adversarial software verification), [Omni-Sentinel](https://lablab.ai/ai-hackathons/vultr-hackathon/omni-sentinel) (containment and audit proofs), and [Halcyon Tech](https://lablab.ai/ai-hackathons/vultr-hackathon/halcyon-tech) (invoice/bank transaction reconciliation with human review). These are **self-described proposals**, not verified product releases or complete competitive research, and may change.

## Competitive takeaway

Neither “sandboxed agent” nor “invoice reconciliation” alone is unique. RUKSA should differentiate through **source-to-execution-to-independent-rule evidence as the contract for task completion**, specialized procurement domain semantics, and a trustworthy approval-gated UX. This is a proposed combination; no claim that no one else has ever implemented it.

## Positioning matrix

| Class | Typical strength | Typical limitation | RUKSA response |
|---|---|---|---|
| Generic chat/copilot | Fast explanation | May not actually execute tasks or validate sources | Execution and deterministic verification |
| Sandbox infrastructure | Strong isolation primitives | Generic infra can lack a complete business workflow | Procurement mission and reviewer experience |
| Invoice matching tools | Domain-specific workflows | Some are opaque or tightly coupled to ERP | Evidence graph and reusable sandbox agent |
| Agent audit logs | Traceability of prompts/tools | Logs do not inherently establish correctness | Independent rule checks tied to input snapshots |

## Differentiating features to build and prove

1. **Proof-gated status:** `VERIFIED` permitted only if input citations and trusted verifier pass.
2. **Two-layer trust:** constrained execution environment plus independent financial checks.
3. **Reviewer-grade evidence:** source row, arithmetic trace, executed code digest, artifact integrity and control-plane-issued verdict.
4. **Human authority:** approval of exact draft action; no silent external changes.
5. **Business-first demo:** show a real exception a controller can understand, then demonstrate isolation.

## What not to claim

Avoid “world's first”, “unhackable”, “fraud-proof”, “guaranteed zero blast radius”, “100% accurate”, “no competitors” or unsupported customer savings. Product originality judged by demonstrated behavior and clear differentiation, not maximal number of claimed features.
