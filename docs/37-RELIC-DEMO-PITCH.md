# RUKSA RELIC — Demo Script & Judging Story

Tagline: **Old software shouldn't take essential services with it.**

## 3-minute stage demo
0:00–0:20 — Show intentionally dated, hard-to-use community service request site; note lost source/test knowledge.
0:20–0:45 — Click Discover; isolated agent browser actually explores valid/invalid flows on owned site; show observation trace, not AI narration alone.
0:45–1:10 — Show Behavior Genome with OBSERVED fields and UNKNOWN back-end assumptions.
1:10–1:40 — Click Rebuild; Vultr Serverless Inference generates constrained UI program; disposable worker builds and runs it. Before/after visual split.
1:40–2:10 — Parity Arena executes both sides with the exact same synthetic input; show a deliberate validation regression rejected, then repair and pass.
2:10–2:35 — Run sandbox containment moment: harmless runaway process timed out, forbidden egress denied, host health preserved; show actual logs/measurements.
2:35–3:00 — Export Revival Capsule: source, captured behavior, replayable parity tests, coverage gaps, security notes; explain business future and limits.

## Judge rubric mapping
- Technology: Vultr Cloud Compute orchestration and deployment, Serverless Inference real calls, isolated Playwright/code execution, actual build/parity output.
- Originality: behavioral archaeology to functional accessibility-forward restoration; unknown-rule ledger, not screenshot clone.
- Business value: institutions with legacy web workflows and missing tests can scope modernization from verified behavior.
- Presentation: a dramatic old-to-new live side-by-side transformation that ends with executable output and a rejected bad candidate.

## Submission
Public GitHub, live web UI on Vultr, architecture details, short video with containment and the model actually producing code or browser steps, disclosed limitations. Confirm official cutoff and exact policy from event site before final upload.

## RELIC 2.0 signature moment

The centerpiece is the **counterfactual discovery of a missing requirement**: the first rebuilt interface looks modern and functional but allows a too-short urgent report. The paired run produces a red behavioral mismatch, a bounded probe shows a minimal reproducible failing input, and an actual code revision passes the same case. The exported Continuity Passport includes exact case input and all known unknowns. Show the real containment test separately; never conflate a parity PASS with sandbox security.
